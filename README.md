# Ecommerce Frontend Design

A pixel-perfect eCommerce frontend project built using HTML, CSS, and JavaScript.

This project recreates the provided Figma UI design with clean structure, reusable styling, responsive layouts, and professional frontend practices.


## Project Pages

- Home Page
- Products Page
- Product Details Page
- Cart Page


## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)


## Features

### Home Page
- Hero Banner
- Featured Categories
- Deals & Offers
- Recommended Products
- Supplier Section
- Newsletter Section

### Products Page
- Product Grid
- Sidebar Filters
- Sorting Options
- Pagination

### Product Details Page
- Product Gallery
- Product Information
- Price Section
- Related Products

### Cart Page
- Add to Cart
- Remove Items
- Quantity Selector
- Coupon Section
- Checkout Summary

---

## Functionalities

- Dynamic Cart System
- Toast Notifications
- Product Quantity Updates
- Coupon Apply Interaction
- Cart Total Calculation

---

## Design Goal

The main goal of this project was:

- Pixel-perfect Figma replication
- Clean frontend structure
- Reusable CSS
- Beginner-friendly code
- Professional UI implementation
